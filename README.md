# Go-P2P-File-Sharing-System
Système P2P hybride en Go pour l'échange de fichiers. Inclut un Super-Pair (index) utilisant des micro-services via Goroutines/Channels pour l'enregistrement et la recherche. Les clients agissent comme des pairs capables de partager et télécharger des fichiers directement. Implémentation complète des protocoles de communication réseau.
